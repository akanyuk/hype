# Светлая тема после перевода цветов на переменные

Цвета заменены генератором `tools/display-settings/themeify.mjs`: каждый цвет получает токен
`--{тип}-{оттенок}-{светлота L*}` с точным исходным значением. Близкие оттенки не сводятся,
поэтому светлая тема не меняется.

## Десктоп (`synio-hype-mod`)

- 785 вхождений → 235 токенов.
- 68 объявлений оставлены литералами: Chromium отбрасывает их при разборе
  (`-moz-`/`-o-`/`-ms-` градиенты, `linear-gradient(top, …)` без `to`). С `var()` они прошли бы
  разбор и обнулили бы предыдущее рабочее объявление.
- Inline-цвет в `blocks/block.events.tpl` вынесен в класс `.block-events-date`.
- Сравнение с эталоном `t4`: 21 скриншот, 0 отличий.
