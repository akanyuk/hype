# hype
Source code of hype.retroscene.org and its docker dev environment.

- `public_html/` — the site (LiveStreet CMS)
- `docker/`, `docker-compose.yml`, `Makefile` — dev environment (`make up`)
- `tools/display-settings/` — verification tools for the dark theme and large font
- `tools/opengraph/` — tests for link previews (Open Graph): `cd tools/opengraph && npm test`
